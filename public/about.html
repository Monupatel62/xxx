About Catch the Coin

Catch the Coin is a free, browser-based arcade game where you control a basket and catch falling gold coins before they hit the ground. Race against a 60-second timer, survive 3 escalating difficulty stages, and beat your personal high score — no download, no login, no install required.

▶ Play Now — It's Free

How to Play

  • Desktop: Use the ← → arrow keys (or A / D) to move the basket left and right.
  • Mobile / Tablet: Tap the screen to move the basket toward that spot.
  • Catch a gold coin → earn 10 points.
  • Miss 3 coins → game over.
  • Survive all 3 difficulty stages within 60 seconds for the top score.

Game Controls

  • ← → or A / D — Move basket
  • ESC or P — Pause / Resume
  • M — Mute / Unmute sound

Game Features

  • 60-second countdown timer — score as many coins as you can
  • 3 difficulty stages — coins fall faster and spawn more frequently
  • High score saved locally — your best score persists between sessions
  • Particle effects on coin catch and miss
  • Synthesized Web Audio API sound effects and background music
  • Pause anytime and resume where you left off
  • Works on Chrome, Firefox, Safari, Edge, and any modern browser
  • Touch-friendly for mobile and tablet play
  • Completely free — no ads interrupting gameplay, no account needed

About the Developer

Catch the Coin was designed and built by Monupatel62 as an open-source web game project. The game is built entirely from scratch using vanilla TypeScript and the HTML5 Canvas API — no game engine, no framework, just pure code.

The project started as a learning exercise to explore game architecture, real-time rendering, collision detection, and audio programming in the browser. It has grown into a polished, fully featured arcade game.
